WHAT IS IN EACH FOLDER
01 Brand Book              The rule book. 37 pages.
02 Logos                   Every logo in every color. PNG for everyday use, SVG and PDF for printers and designers.
03 Colors and Fonts        The color codes, the palette card, the font names and how to set up Canva.
04 Social Media            Profile pictures, post and story templates, photo frames, highlight covers, cover photos, shop banners.
05 Website                 Tab icons, header logos, banners, email images and a style file for a web designer.
06 Print and Packaging     Print-ready PDFs for cards, tags, stickers, labels, a gift certificate and tissue paper.
07 Patterns and Icons      Repeating patterns, small icons and decorative pieces.

WHICH FILE TYPE TO USE
PNG   Use these almost everywhere. Logo PNGs have a see-through background.
SVG   Stays sharp at any size. Opens in a web browser. Send to printers, sign makers and web designers.
PDF   Send to print shops.
